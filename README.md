# 6ページ構成コーポレートサイト

情報量の多かったサイトを、次の6ページに整理し直した静的サイトです。

| ページ | ファイル | 役割 |
|---|---|---|
| トップ | `index.html` | 全体の入口。強み → サービス → プロジェクト → 採用 → 問い合わせの順に誘導 |
| サービス内容 | `service.html` | 特殊技術のアピール。考え方 → 4つの技術 → 施術の流れ → 対応症状 |
| 会社概要 | `company.html` | 代表挨拶、会社概要表、沿革、理念 |
| 軍艦島プロジェクト | `gunkanjima.html` | 概要、背景、3つの取り組み、これまでの歩み、今後 |
| 採用情報 | `recruit.html` | 管理職中心。募集背景 → 3ポジション → 募集要項 → キャリアパス → 選考の流れ |
| お問い合わせ | `contact.html` | 電話・メール・入力フォーム・個人情報の取り扱い |

## 構成

```
index.html  service.html  company.html
gunkanjima.html  recruit.html  contact.html
assets/
  css/style.css   … 全ページ共通のスタイル
  js/main.js      … スマホ用メニューの開閉、フォームの入力チェック
CONTENT.md        … 差し替えが必要な箇所の一覧（114件）
```

ビルド作業や外部ライブラリは不要です。HTML・CSS・JavaScript のみで動きます。

## 表示を確認する

ファイルをブラウザで直接開くだけでも確認できますが、簡易サーバー経由のほうが本番に近い状態になります。

```sh
npx http-server . -p 8080
# → http://localhost:8080
```

## 公開までにやること

1. **`CONTENT.md` の一覧に沿って原稿を差し替える**
   仮置きの箇所は画面上で黄色くハイライトされています。
2. **お問い合わせフォームの送信先を設定する**
   `contact.html` の `<form action="">` に送信先URLを入れてください。
   未設定の間は送信されず、電話・メールでの連絡を促す案内が出ます。
3. **仮置きのハイライトを消す**
   原稿が確定したら `assets/css/style.css` の
   `▼▼ 仮テキスト（プレースホルダ）のハイライト ▼▼` のブロックを削除してください。
4. **写真を入れる**（任意）
   現在は写真を使っていません。院内・スタッフ・軍艦島の写真があると説得力が上がります。

## 編集するときの注意

- **ヘッダーとフッターは6ファイルすべてに同じ内容が入っています。**
  会社名や電話番号を変えるときは、6ファイルまとめて置換してください。
  例：`sed -i 's/旧テキスト/新テキスト/g' *.html`
- **各ページのナビゲーションには `aria-current="page"` が付いています。**
  そのページ自身のリンクに付ける印です。ページを増やすときは付け替えてください。
- **濃紺の背景（`.section--navy`）の中の文字色は、CSS の後ろのほうでまとめて指定しています。**
  `.sec-head h2` などと詳細度が並ぶため、前に書くと打ち消されて文字が見えなくなります。
